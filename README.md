## Project Overview

Retail promotions are widely used to increase product sales, but not every promotion delivers the same business value.
This project analyzes over 17.7 million retail transactions from the Dominick's retail scanner dataset to evaluate promotion effectiveness, identify products that benefit most from promotions, and measure the relationship between promotional activity, sales volume, and gross margin.
## Business Goal


The objective of this project is to help retailers understand:

- Which products benefit most from promotions
- Which promotion types are associated with higher sales
- How promotions relate to gross margin
- Which products should be prioritized for future promotional campaigns

## Analysis

The project currently includes:

- Exploratory data analysis
- Product performance analysis
- Promotion effectiveness analysis
- Gross margin analysis
- SQL-based business metrics
